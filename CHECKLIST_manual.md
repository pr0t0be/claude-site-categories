# Ручная сессия проверки: 20 сайтов за один вечер

Точные записи (`devtools_response`) даёт только человек с открытым DevTools. Эта памятка для такой сессии: обычная работа с Claude in Chrome, а рядом открыт служебный процесс расширения с фильтром `url_hash`. Массового опроса сервера Anthropic скриптом не делаем: это недокументированный эндпоинт под личным токеном.

## Подготовка (один раз за сессию)

1. Chrome с расширением Claude, вход в аккаунт Claude выполнен.
2. `chrome://extensions`, справа вверху «Режим разработчика».
3. В карточке Claude ссылка «service worker» (мелкая, под описанием). Откроется DevTools служебного процесса.
4. Вкладка Network, в фильтр ввести `url_hash`. Поставить галочку «Preserve log», чтобы строки не пропадали.
5. Смотреть только вкладку Response. Вкладку Headers не открывать и не снимать: там токен входа.

## Один сайт (около минуты)

1. В панели Claude: «Открой https://<сайт> и ничего не нажимай». Этого хватает: запрос категории уходит при переходе.
2. В DevTools появляется строка `browser_extension`. Открыть, вкладка Response, поле `category` и поле `domain`.
3. Записать строку в `registry.csv`:
   `<domain из ответа>,<category>,<ГГГГ-ММ-ДД>,devtools_response,<логин GitHub>,<источник>,"<заметка>"`
   Источник: скриншот вкладки Response в `evidence/<domain>_<category>_<дата>.webp`, либо текст `self-report (Response tab seen, no screenshot)`.
   Заметка: версия расширения, `org_policy`, что показало окно разрешения, если оно было.
4. Если строки нет: ответ в кеше 5 минут. Попросить открыть другую страницу того же сайта или подождать.
5. Если категория category3 или category1, по желанию сделать ещё один шаг (клик по безопасной ссылке), чтобы увидеть окно и записать его текст в заметку.

После сессии: `python validate.py`, коммит CSV, скриншотов и README вместе.

## Повтор раз в месяц

Категория может измениться. Раз в месяц повторить сессию по этому списку и по тем доменам, у которых самая свежая строка в `registry.csv` старше 30 дней. Новое наблюдение добавляется новой строкой, старая остаётся: так видна история.

Быстрый список «кто устарел» (домены с последней датой старше 30 дней):

```bash
python -c "import csv,datetime as d;r=list(csv.DictReader(open('registry.csv',encoding='utf-8')));m={};[m.__setitem__(x['domain'],max(m.get(x['domain'],''),x['checked_at'])) for x in r];t=(d.date.today()-d.timedelta(30)).isoformat();print('\n'.join(f'{k} {v}' for k,v in sorted(m.items()) if v<t))"
```
